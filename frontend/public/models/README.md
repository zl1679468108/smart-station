# 驿站 3D 资产目录

把导出的 `.glb` 放到本目录后，前端会按 `manifest.json` 自动探测并替换程序化模型。

## 命名约定

| 文件 | 用途 | 建议尺寸（米，XYZ） |
|------|------|---------------------|
| `shelf-small.glb` | 小货架 | 2.0 × 1.8 × 1.0 |
| `shelf-medium.glb` | 中货架 | 2.4 × 2.2 × 1.2 |
| `shelf-large.glb` | 大货架 | 2.8 × 2.4 × 1.4 |
| `door-main.glb` | 门口 | 宽×高×深 ≈ 门宽 × 2.2 × 0.4 |
| `counter.glb` | 服务台 | 3.2 × 1.4 × 1.4 |
| `locker.glb` | 出库记录区 | 3.0 × 2.2 × 0.8 |
| `office.glb` | 办公区 | 2.4 × 1.8 × 1.8 |
| `parcel-box.glb` | 纸箱 | 0.46 × 0.34 × 0.38 |

## 导出要求（Blender）

1. 单位：米；模型底部中心对齐世界原点，站在 y=0 地面上。
2. 轴向：Y-up；导出 GLB，勾选 Apply Modifiers。
3. 面数：单货架建议 1k–8k 三角面；整仓多实例会用克隆。
4. 材质：PBR（BaseColor / Roughness / Metalness）；避免超大 4K 贴图。
5. 变换：导出前 `Ctrl+A` Apply All Transforms。

## 行为

- 文件不存在或加载失败 → 自动回退程序化几何，不影响布局编辑。
- 文件存在 → 按 `targetSize` 等比适配包围盒后渲染。
- 改模型后强制刷新浏览器（必要时清缓存）。

## 占位模型

仓库已内置程序化生成的占位 GLB（货架/门/服务台/出库记录区/办公/纸箱），保证大屏与工作台立即可用。

重新生成：

```bash
cd frontend && npm run gen:models
```

用 Blender 导出的真实中模覆盖同名文件后，**刷新页面**即可自动替换（失败自动回退程序化几何）。
