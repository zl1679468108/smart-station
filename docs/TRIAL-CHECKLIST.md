## 3. 入库 + 通知（必测）

1. 系统管理 → 驿站：打开「到件通知」、填地址/电话/营业时间  
2. 系统管理 → 通知公示：确认客户绑定引导文案是白话  
3. 入库（扫码/手动）：
   - 手机号填齐后显示是否已绑定通知（未绑定会高亮，可复制绑定话术）
   - 连续同收件人默认开；扫完运单回车可直接入库
   - 成功后能复制取件码、光标回到运单号
   - 通知状态：已私信 / 未绑定 / 失败 可读
   - 有到付/货款时成功区醒目待收款，可去出库收款
   - 填金额时实时显示待收合计
   - 本会话显示成功件数 / 未绑定 / 待收款，可清零（扫码/手动）
   - 成功区/最近列表可「看包裹」进库存详情
4. 网络抖动时：免费通道会自动短重试（最多 3 次）；通知记录通道文案可见「重试后成功 / 试了N次」
4c. 私信失败：入库本会话会累计「私信失败」，可「一键补发本会话失败」（最近5条）；触达条/通知页也可今日批量补发
4d. 绑定分享链接应带 stationId（多驿站时打开查件页会落到对应站）
4e. 交班：有私信失败时先点「补发私信失败」；批量入库可筛「私信失败」并一键补发
4f. 滞留：提醒后若有失败，点「一键再发失败」；扫描机/出库成功页可进补发失败私信
4b. 未绑定客户：店员可复制「绑定链接话术」一对一发给客户；查件有在库件时自动展开绑定区；结果页可复制取件码/全部码 +「两步取件·绑定后自动收码」+ 包裹卡「绑定后可微信收此码」；全端底部固定绑定条；未查到也可先绑定；**绑定成功后自动给在库包裹私信取件码**并 toast 补发件数（近 6 小时已私信的不重复）；入库页可「补发通知」；批量可「一键补发未私信」  
5. 入库页顶部「今日到件触达」与工作台同源：件次私信率/人数覆盖/今日新绑/未绑定/失败可点进通知；手机号未绑定强提示；入库成功未绑定有三步引导+复制当面/绑定/组合话术；会话可复制未绑定清单  
5b. 工作台「今日到件触达」→ 点整卡看今日；点「未绑定/已私信/私信失败」进对应筛选；未绑定可「按手机号跟进」  
6. 通知记录：顶部今日触达漏斗可点选；筛选 今日 / 发送失败 / 到件 / 滞留 / 未私信 / 已私信 / 私信失败；本页可一键补发未私信；有关联包裹时点「看包裹」进库存详情；库存详情可按手机号跳回通知记录  
7. 未绑定：入库成功可复制「当面话术/绑定引导」；工作台可复制绑定话术  
8. 滞留：单件/批量「发提醒」后可见触达回执（已私信/未绑定）；可进通知记录  
9. 通知记录：分页 + 导出 CSV；时间窗今日/近3日/近7日；「按手机号」聚合未私信客户（可只看仍未绑定）；可一键复制未绑定跟进清单（含手机号，勿发群）  
10. 工作台：滞留待办进滞留页提示扫描提醒；预约待办直达今日/待确认  
11. 交班：有待收款时弹窗提醒，可跳转库存筛选；可导出本班快照  
12. 入库：扫已在库运单会醒目提示取件码，禁止重复提交  
13. 批量入库：支持 Excel 粘贴/表头/+86；可「仅预检」或「预检并导入」；预检含手机绑定率；成功清单可筛选未私信/已私信；可导出/复制未私信跟进清单；点取件码或「看包裹」进详情  
14. 出库待收款：工作台/交班/库存详情均可直达出库收款；须选方式并勾选「已当面收妥」；成功后可复制收款话术  
15. 工作台「今日收款日结」显示已收金额与笔数，可进明细  

**隐私**：企微群不得出现完整取件码、完整手机号、验证码。

## 4. 业务闭环速测

| 模块 | 动作 |
|------|------|
| 出库 | 页顶今日触达；手机后 4 位核验；待收款须先收；成功回执按绑定状态引导（未绑定复制话术/近3日）；可打印取件回执；扫描机成功页同逻辑 |
| 滞留 | 页顶今日触达；立即扫描；发提醒后回执含未绑定三步引导/复制话术/近3日；库存详情单件提醒同逻辑；可打印小票/复制催取话术 |
| 异常 | 页顶今日触达；卡片可看包裹/通知、复制当面话术；在库/滞留可补发到件；可打印小票/引导绑定 |
| 预约 | 页顶今日触达；查件页预约成功可强引导绑定；后台代客/确认回执按是否未绑定分色引导；可复制话术/近3日跟进；可打印预约凭条 |
| 交接班 | 页顶今日触达；开班 → 入出库 → 交班快照；交班可见人数覆盖/今日新绑/未绑定/私信失败并跟进；工作台有「今日跟进」优先清单与摘要；交班跟进清单可复制摘要 |
| 财务 | 收款日结含今日触达条；可未绑定跟进/复制绑定话术；直达待收款出库与今日通知；收款日结可复制摘要/打印 |
| 寄件 | 页顶今日触达；列表可复制进度话术、按发件手机看通知；状态更新有回执；可打印寄件回执 |
| 统计 | 可见件次私信率/人数覆盖/今日新绑；绑定转化（到件→新绑→覆盖）；可复制/导出今日与近3日未绑定清单；漏斗/滞留白话说明 |
| 工作台/大屏 | 顶部「今日跟进」优先清单可复制摘要；今日触达含件次私信率/人数覆盖/今日新绑；近7日绑定转化速览；可进近3日未绑定；大屏有到件触达速览 |
| 查件 | 有件自动展开绑定；结果可复制取件码/全部码；两步取件+底部绑定条；绑定后补发在库码；预约可引导绑定 |
| 入库 | 扫码/手动/批量；成功 toast 区分已私信/未绑定；未绑定三步引导+复制话术；会话未绑定清单；批量预检与结果可跟进；可打印取件码小票（可勾选入库成功自动打印） |
| 库存 | 页顶今日触达条与入库同源；补发前可按手机号跟进未绑定；可打印/批量打印/打印本页取件码小票 |
| 扫描机 | 出库成功可复制绑定话术；扫描页可见今日未绑定摘要 |
| OCR | 面单识别回填；失败可重新识别/换一张；确认后再入库 |

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| 入库成功但客户没收到 | 看是否绑定；未绑定引导查件绑定后补发 |
| 企微看到取件码 | 异常，检查是否误用完整 content 进 wecom |
| 查件不是本站数据 | 配 `VITE_KIOSK_STATION_ID` |
| 预约表不存在 | 执行 `migration-appointments-m50.sql` |
| OCR 突然全失败 | 看月额度是否触顶 |
